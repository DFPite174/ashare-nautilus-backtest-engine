# 能力矩阵与验收边界

本项目定位为 A 股候选策略的规则、账户与 NT 执行回放核验层。下表区分实现能力与证据；“已实现”只在声明的输入契约和模型假设内成立，不代表全部历史制度或实盘已经验收。

| 能力 | 普通股 | 基础可转债 | 当前限制或证据 |
| --- | --- | --- | --- |
| 市场与账户 | 沪深、人民币现金多头、共享资金 | 沪深、人民币现金多头、可与股票共享资金 | 不含北交所、融资融券、保证金与做空 |
| 持仓可卖性 | T+1 批次约束 | T+0 同日回转 | 可转债同日回转为合成测试证据 |
| 数量与报价 | 历史规则中的申报数量、整手及零股检查 | 默认 10 张一手、0.001 元报价；按输入契约校验 | 历史证券日规则须由上游提供并核实；不是全历史制度自动生成器 |
| 停牌与价格边界 | 按输入日规则阻断；未提交意图在停牌日拒绝 | 使用同一日规则框架 | 未重建集合竞价、逐笔队列和盘中临时停牌过程 |
| 委托与成交 | 下一 Bar 开始的 IOC、DAY 限价、部分成交与日终撤单 | 复用相同执行模型 | OHLC 合成深度；NT 使用 L2 撮合不等于输入是真实 L2 |
| 资金与费用 | 含费用资金预留、日期费率或自定义费用、卖出回款再买 | 可转债费用分支、卖出免印花税、混合资产区分 | 费用模型需按具体账户校准；未以券商逐笔账单验收 |
| 权益处理 | 税前现金红利、应收与到账、送转及新增股份上市日 | 不支持可转债生命周期权益 | 不含转股、赎回、回售、付息和到期结算的完整账户闭环 |
| 日终核验 | 原生/参考现金、三方持仓与权益核对 | 基础交易账户核对 | 核算路径独立，不证明共同输入和撮合假设真实 |
| 行情证据 | 本地 Tushare 股票日线及历史规则/权益工程回放 | 合成行情交易测试 | 本地股票湖回放不能证明真实转债数据路径通过 |
| 追溯记录 | 输入/运行哈希、策略参数、环境与源码指纹 | 复用同一运行记录 | 指纹记录内容身份，不创造历史版本 PIT 证据 |
| 数据投递与复用 | 完整、逐日流式、日线稀疏；校验后准备数据可重复运行 | 流式与稀疏已有合成基础交易案例；真实湖实验仍是普通股 | 稀疏仅日线；跨轮重新建立账户；保存旧状态及原始容器增加内存，详见投递与准备契约 |

## 执行模型

`bar-synthetic-l2-v1` 把未复权 OHLC 转为 O→H→L→C 的合成深度，交由 NT 原生 L2 撮合；所有方向与委托共享 Bar 量预算。盘中触价按限价处理，开盘允许价格改善，可配置逆向滑点压力。固定路径、触价资格与整 Bar 事后量预算均为研究假设，不能据此证明真实开盘容量或排队成交概率。

## 数据与研究边界

输入检查会拒绝已识别的缺日历、缺规则、开放交易日缺行情及公司行为冲突；检查通过不等于数据完整性、历史股票池和所有公司行为已获独立认证。当前本地供应商快照属于当前版本历史数据，历史版本时点一致性（historical vintage PIT）未验收。因子和信号可得时间、训练/验证隔离、存活偏差、策略 alpha 与样本外有效性由上游研究流程另行验证。

## 性能与运行边界

已有一次 500 股、五年的本地工程运行，说明该具体输入与工作负载完成运行；它不构成生产服务等级（SLA）、全市场多年分钟容量或多人并发承诺。性能应同时说明证券数、交易日/Bar 数、订单密度、权益事件、计时边界和内存测量方式，不能把 Python 分配峰值当作进程总内存。既有负载口径见 [本地验证](local-tushare-validation.md)。

当前未验收真实券商通道、盘中故障恢复、实时风控、实盘账单对账和生产运维。未来实盘层的职责见 [分层架构](architecture.md)。完整送转还受 [固定 ABI 环境](environment.md) 限制。

## 使用结果时保留的区分

- 工程测试通过：证明指定案例满足断言。
- 供应商数据回放通过：证明该快照上的执行及账户路径。
- 独立参考账本核对通过：证明声明模型下账目一致。
- 初筛或策略收益较好：需要额外研究验收，不能由上述工程结果推导。
- 实盘可实现性与生产验收：仍需市场、券商和运维证据。
