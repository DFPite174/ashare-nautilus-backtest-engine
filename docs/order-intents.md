# 订单意图契约

`OrderIntent(symbol, side, quantity, limit_price=None, intent_id=None, earliest_execution=None)` 保留原有前四个位置参数。该冻结数据类表示策略请求；请求通过校验不等于交易所已经成交。

- `symbol` 必须存在于本次运行的证券主表。`side` 接受 BUY/SELL，大小写不敏感。`quantity` 必须是正的 Python 整数，布尔值无效。
- 可选 `limit_price` 必须有限、为正且为证券最小报价单位的整数倍；不会自动取整价格。
- 可选 `intent_id` 必须是至少含一个非空白字符的非空字符串，且在整个运行内唯一。按原值精确比较，不裁剪或归一化；重复 ID 报错，不静默去重。匿名意图可以重复。
- 可选 `earliest_execution` 必须是带时区的 datetime，等于或晚于回调决策时间；等号有效。不同时区按实际时刻比较，无时区时间被拒绝。

引擎从已结束 Bar（组合回调使用共同结束时间）提供决策时间，策略不能倒填创建时间。整个回调批次校验成功后才登记 ID 和入队。`validate_intents(intents, master, decision_time, seen_ids)` 将可迭代输入物化，按原顺序返回原意图对象，成功后才更新调用者持有的运行 ID 集合；无效批次不改变该集合。

执行仍基于下一根符合条件的 Bar 开始时刻。有效门槛是决策时间与所给 `earliest_execution` 的较晚者，Bar 开始时间必须不早于门槛。若最早时间落在 Bar 内，不会允许使用该 Bar 后续盘中价格路径。未来日期会延后资格，不会制造期间报价；获得资格后仍适用已有非活动交易日处理。

该字段是执行资格门槛，不是订单过期时间，也不覆盖有效期。未给限价的意图仍在下一 Bar 使用 IOC；显式限价在提交后使用 DAY。符合时间条件后仍须通过流动性、账户、交易时段、价格边界和证券规则检查。

有停牌占位 Bar 时，执行资格不晚于其开始的意图按现有规则拒绝；没有占位 Bar、但在非开放日收盘前已取得资格的意图，最迟在该日收盘记录拒绝。刚在非开放日收盘产生的意图属于未来 Bar，不在本日拒绝。日初已符合资格的既有意图仍可在日初被拒绝，拒单时刻随已知状态与资格时间而定。

提供的 `intent_id` 会保留在成交、拒单、原生订单及期末待执行记录中。`BacktestResult.to_dict()` 的 `schema_version=2` 标识这些兼容新增字段，既有字段保留；匿名意图不补造业务标识。输入 manifest 的编码版本保持原样，代码与策略变化仍改变运行指纹。
