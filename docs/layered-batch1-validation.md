# 分层执行验证改造：第一批验收（2026-11-12）

版本：2.2.0。定位为 A 股规则与账户适配、NT 候选执行回放及独立核验。此批次是已批准改造清单的首批实现，剩余工作见 [执行计划](superpowers/plans/2026-11-12-layered-validation.md)。

## 本批交付

- README、分层架构、普通股/基础可转债能力矩阵及账户/意图/调仓契约。
- `OrderIntent` 保留原四个位置参数，新增可选 `intent_id` 与 `earliest_execution`；整批校验、运行内标识唯一、成交/拒单/订单/期末未执行全链路关联。
- `plan_rebalance` 复用 `TargetWeights`、交易单位与费用逻辑，离线生成可检查计划；应收计入权益且不可用于支付，预计卖款资助买入以实际成交为条件。
- `ResearchState` 增加时点、可用/预留现金、应收、净值与分证券估值时点；快照只读、历史前缀固定。
- manifest 去除 `asdict/deepcopy`，按有界行流式计算原编码 SHA-256；输入摘要与基线一致。
- 空待执行队列早退；NT 公司行为按除权/派息/登记日索引。原成交模型、严格输入检查和每日三方对账保持开启。

## 验证

- 源码完整测试 **222 passed**；2.2.0 平台 wheel 安装到独立目录、仓库外导入及桥接检查通过，完整测试 **222 passed**。
- 日线、分钟示例均 **2 笔成交、3 个日终对账，现金 100039.43**。
- 冻结 Tushare 导出：500 股、2021—2025 年、605069 根日线、1212 个交易日、1170 个意图，另运行 10 个真实数据工程场景。原始数据库不上传。
- 三次串行新进程复测，各有 **1155 笔成交**；成交、拒单、每日现金/权益/持仓、期末资金和持仓与冻结基线精确一致；输入 SHA-256 同为 `604f7bdabc77693f673ed0372db92d049d660a672e318e35704ba9b0f00e0ac3`。
- 公司行为现金日志逐事件及金额匹配；来源表同日独立事件行序可不同，因此日志按完整事件内容比较，逐日账户轨迹仍按日期严格比较。此处未声称原始 JSON 字节相同。
- 独立审查及新增测试覆盖时点门槛、停牌无 Bar、停牌收盘新决策、标识、预留资金、未到账分红及调仓资金约束。

全量回归发现并修复了日终将当天收盘新意图误判为本日待执行意图的问题；修复前两次结果已排除，以上三次采用修复后的执行逻辑。

## 继续顺序

下一批先做完整准备数据的复用/失效契约与增量状态，再验证活动订单索引和稀疏事件原型。简化成交路径须先通过共同执行契约与容量/限价/资金/权益回归；未达目标时才评估新增后端。快速层差异归因、生命周期扩展与 ABI 维护仍按计划推进；分钟/实盘深化和完整可转债生命周期属于条件任务。

现有真实供应商快照不是严格历史 vintage PIT；对账与工程场景不证明真实成交、全部 A 股规则或策略 alpha。本批未新增快速组合内核、真实盘口模型或实盘连接。
