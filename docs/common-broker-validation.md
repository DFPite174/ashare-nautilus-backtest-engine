# R9：独立原生 broker 的共同规则对账

2026-11-16；本项目执行核保持 **2.7.0**，本批只增加独立实验、比较检查与证据，不修改执行模型或安装依赖。

## 实验问题与范围

前几批主要验证独立金额预期、账户核验和本项目多条回放路径。本次补充另一个撮合器：在双方共同覆盖的最小场景中，比较同一市场输入、固定指令与费用后的成交和逐日账户；不把比较器相等当作全市场、全部 A 股规则或真实可成交性证明。

| 项目 | 固定条件 |
| --- | --- |
| 市场输入 | 只读指定本地 Tushare 湖；`000001.SZ` / `600000.SH`，2025-01-02—2025-01-10，7 个官方交易日、14 根原始日线，成交量单位为股 |
| 信号与资金 | 初始 10 万元；首日收盘各买 100 股，第二日收盘各卖 100 股；预计第二/第三交易日开盘执行，共 4 笔成交 |
| 共同规则 | 原生市场单次日开盘撮合、共享现金、持仓估值、充分资金和相同费用假设；不启用收盘成交或开盘前知晓当日价格 |
| 预先检查 | 全样本连续有效行情、规则 `OPEN`、没有实施权益、开盘严格在官方涨跌停之间、每根量的 1% 足够 100 股；输入不满足则失败，不默默换股 |
| 本项目 | NT 原生执行 + 现有规则/账务层，参与率 1%、滑点 0，原生日终核验和独立逐笔现金重算保留 |
| 外部参照 | 本地干净的 Backtrader **1.9.78.123** / `b853d7c90b6721476eb5a5ea3135224e33db1f14`；保留原生 Cerebro / BackBroker / PandasData 和订单生命周期 |
| 最小适配 | 固定指令策略、结果采集及公开 `CommInfoBase` 费用钩子；没有补写 T+1、停牌、权益、涨跌停或容量引擎 |

双方输入来自同一已校验的 Bar 列表；Backtrader 按其接口转换为 Pandas OHLCV，精度差异只允许 **0.0000001 元**以内的浮点噪声，不能吞掉分级甚至千分级费用差异。持仓、数量、方向和日期精确比较。

## 结果及首个差异

| 对照 | 结果 | 原因 |
| --- | --- | --- |
| 沿用历史实验的未取整费用口径 | 不相等 | 首差 `fills[0].fee`：本项目 **5.01** 元，外部费用适配器 **5.01144** 元；超过浮点噪声容差 |
| 明确采用逐笔费用按分四舍五入 | 共同规则通过 | 同一自定义费用钩子增加取分，撮合器保持原生；4 笔成交的日期、价格、数量、费用，以及 7 日现金、持仓和净值全部一致 |

本次没有发现需要修复本项目执行核的差异。统一费用是公开的模型适配，不称为 Backtrader 默认 A 股费用能力，也不把取分前的不一致删掉。摘要 `docs/evidence/common-broker-summary.json` 同时保留两组结果、首差、双方代码指纹和源数据快照；不发布原始行情表或完整成交价格文件。

## 能得出的结论与停止条件

当前版本在这组**已完成约束准入、固定数量、次开盘、无事件的共同规则场景**中，与独立 broker 结果一致。该证据补充 P0 独立预期与 P1 重复回放，并不取代它们。

未验证 Backtrader 的 A 股 T+1 强制执行、停牌拒单、分红送转、退市、部分成交、共享容量或完整周频目标反馈。对照按日期对齐，不证明盘中时间戳、同刻排队顺序或真实成交等价；本次也不比较运行速度、不据此决定替换内核。供应商历史版本和历史股票池限制仍然存在。

R9 的必要共同规则子集已完成，没有新缺陷或容量阻断。停止继续扩充竞品适配，保持当前执行核冻结；后续只有真实候选触发差异、实际数据缺口或等待预算问题时，才重新开启相应任务。
