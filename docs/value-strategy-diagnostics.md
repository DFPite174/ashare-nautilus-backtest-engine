# V 策略冻结结果诊断

本次只读取已冻结的 2021—2023 年 V/R30 执行结果及其派生公司行为表，不重跑或修改策略、执行核、费用和输入，不评价最终留出期。输入及脚本指纹见[公开摘要](evidence/value-strategy-diagnostics.json)，原实验口径见[V 接入](value-strategy-integration.md)。逐股逐日明细仅保存在本地。

## 账户利润如何组成

初始资金均为 1,000,000 元。下表使用实际成交、账本现金流水和期末估值，先以 Decimal 精确校验恒等式，再展示到分。

| 金额（元） | V | R30 |
| --- | ---: | ---: |
| 卖出本金 − 买入本金 + 期末持仓市值 | −119,692.57 | 340,385.28 |
| 已到账现金分红 | 158,899.68 | 42,346.30 |
| 碎股现金替代 | 133.44 | 40.04 |
| 其他现金流水 / 期末应收红利 | 0.00 / 0.00 | 0.00 / 0.00 |
| 减：已记账交易费用 | 14,780.43 | 6,346.86 |
| 净利润 | **24,560.12** | **376,424.76** |

R30 比 V 多盈利 351,864.64 元，其中已观察费用差对该差额的会计贡献为 8,433.57 元。保持实际路径、仅在纸面加回已记费用，利润分别为 39,340.55 和 382,771.62 元；这不是零费用反事实回测，费用改变可能影响资金和后续订单。10 bps 滑点仍含在实际成交价格中，没有单独估计。

这是会计分解（accounting decomposition），不是因果收益归因。原始不复权价格会在除息时向现金分红转移价值，不能把第一行直接解释为选股亏损，也不能把现金分红单独解释为额外收益。解释价值因子、行业或个股贡献需要另立上游研究，当前证据不支持这些因果结论。

## 为什么实际持仓会超过 Top30

目标从 `execution_date` 生效，信号日收盘仍对应上一组目标。V 有 55 个交易日的持仓数超过当期目标数；118 个交易日持有非目标股票，共 118 个“股票×交易日”，最高 31 只。R30 对应三项均为零，最高 30 只。

| V 非目标持仓的记录原因 | 股票×交易日 |
| --- | ---: |
| 规划阶段 `INACTIVE`，退出未申报 | 37 |
| 执行阶段 `LIMIT_DOWN_CLOSE` | 22 |
| 执行阶段 `SUSPENDED` | 38 |
| 定量后、执行前发生送转 | 21 |
| 未分类 | 0 |

这些是持仓持续天数，不是拒单次数或独立事件数。脚本使用规划记录、执行反馈和执行日实际持仓分类；若缺少解释证据，会保留 `UNCLASSIFIED`，不推定成交错误。

最后一类的实际算术为：收盘按旧仓 4,100 股计划全部卖出，次日开盘前 1.2 倍送转得到 4,920 股，原卖单成交 4,100 股，仍余 820 股；这部分持续 21 个交易日，到下次调仓处理。因此订单 `FILLED` 表示申报数量全部成交，并不保证策略的清仓目标实现。当前一次申报、不追单的固定数量政策下，不能把它当作股票丢失或漏记账。

V/R30 日末现金占权益的均值为 1.8116% / 0.7816%，这里只作描述，未估计现金拖累。所有残仓可解释也不代表成交模型已复现真实市场。

## 复跑和后续决策

在仓库根目录使用已有私有实验输出：

```powershell
python examples/diagnose_value_strategy.py --run ../benchmark/value-strategy-readonly-final --output ../benchmark/value-strategy-diagnostics-recheck
```

脚本拒绝覆盖输入目录，核对冻结结果与公司行为表哈希及模型可比性；输出 `summary.json` 和含逐股信息的 `private_details.json`，后者不提交。源码和仓库外已安装 2.7.0 执行核各 374 项回归通过，执行核保持不变。

本次没有证据要求继续改造内核。后续优先在上游登记并分析 V 的总回报与暴露，保留当前基线。如果确需按送转后股数清仓，应独立提出“按目标重定量”执行政策并比较账户路径，不以修复名义悄然改变当前结果。现金替代、供应商历史版本、合成日线成交及未建模个人递延红利税等原实验限制继续适用。
