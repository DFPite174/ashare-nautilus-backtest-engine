## 冻结执行回归单独记录

原冻结实验的 10 个工程场景及 500 股五年轨迹另运行一次，保持成交、费用、拒单、逐日资金/持仓/权益、期末账户及完整公司行为事件一致，大样本仍为 1155 笔成交。其市场摘要为 `604f7bdabc77693f673ed0372db92d049d660a672e318e35704ba9b0f00e0ac3`，核心源码摘要 `bc85e50163ea8430d8937e215a6192baf526780d9811b76276d74efdd08ba64a`。

直接湖测量采用接入器默认权益策略，冻结实验采用另一显式策略，两个输入摘要不同，不混同为同一执行实验。生产直读实验验证输入内容身份与准备成本，不声称该路径完成全量策略执行。原数据库只读，原始行情与凭据未上传。

## 剩余范围

生产直读的加载/准备峰值仍超过 1 GiB；全程执行 ≤20 秒也未在此证明。保留 Python Bar/规则对象仍有成本，是否继续新增紧凑公共输入接口须先评估实际收益与兼容风险。活动订单/统计热点与真实快速层对照仍按必要 P0–P2 计划推进；ABI 重构、新后端、真实盘口、实盘与完整转债生命周期继续暂缓。
