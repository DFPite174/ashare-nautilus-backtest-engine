# 第十批：空持仓送转重建优化（2026-11-16）

版本 **2.6.1**。第九批 2.6.0 在本日补齐交付：源码、独立 wheel 各 349 测试通过，6 个本地源文件指纹未变化，已同步 GitHub `c6f95ac`，Windows CI 成功。第九批原性能保留 11 月 13 日测量日期；以下是本日新测。

## 诊断与最小改动

关闭最终汇总后的 128 股诊断中，实时 `record_trade` 约 4.35 秒，日初 `_start_day` 约 2.06 秒。单独插桩发现 **28 次**送转重建均对应无原生持仓证券，合计约 **1.63 秒**；插桩只作定位，账务与基线一致，不作为正常计时。

本批只保存 `positions_open` 查询结果，逐原生持仓桥接调整后，在列表非空时才调用组合重建。网关送转、参考账本、权益及估值处理保持；有持仓送转仍桥接并重建。没有替换 NT 内部统计、改队列或新增公共接口。

新版核心源码摘要 `9f0b9e5eac3588ef89c70dda685e38be81465287f563869aa0bcaffc1e046415`。Git 记录为运行时基线，代码由源码指纹、本批提交和安装包验证共同追踪。本批基线为 2.6.0，两个版本都已显式设置相同的模拟申报保护阈值，未借改变限流来比较性能。

## 自主复核后的下一步

保留这一局部改动，停止扩大本轮权益路径重构。实时统计仍有成本，但不直接替换 NT 内部对象。

下一步先按阶段测量长周期准备峰值和对象归属，再决定是否能复用覆盖键或减少重复对象；仅优化真正影响峰值的阶段，不根据函数耗时猜内存来源。公开列式接口、队列索引和新后端继续暂缓。真实快速层归因仍需要实际上游输入。

本批不改变输入存储，不能宣称解决完整 500 股五年 1 GiB；首次执行 20 秒也尚未全面达成，P0–P2 仍未整体完成。OHLC 合成路径、事后 Bar 量、vintage PIT 缺口与固定 ABI 边界保持。
