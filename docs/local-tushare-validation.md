日期：2026-11-12。数据源为用户本地 `Tushare_DB` Parquet 湖，未复权日线、官方日历、涨跌停、停复牌、实施分红及送转。接入保持只读，行情文件与凭据保留在本地。

## 复验

```powershell
python -m pytest -q
python examples/validate_tushare_lake.py --root "C:\path\to\Tushare_DB" --output local-validation.json --benchmark
```

验证脚本按固定意图逐笔检查成交、现金和持仓，不以策略收益为验收条件。费用使用自定义佣金万二、最低 3 元，以覆盖已修复的自定义配置路径。基准现金按成交金额、费用、公司行为现金流独立加减核算，并核对每日日终结果。

## 数据核查

- 源文件 `manifest.json` 创建于 2026-11-09、更新于 2026-11-10；历史数据属于当前供应商版本，`historical_vintage_pit=false`。
- 分红表存在同一已实施事件的多条记录。经济条款及实施日期一致时显式去重，冲突时报错。
- 预案等未实施状态按明确枚举筛除，排除条数写入快照。已实施事件缺少关键日期时记录数据缺口。
- 日历要求区间内每天一条有效 SSE 记录，再从中选择开市日；缺日期、重复日期或行情落在非交易日时失败。
- 原始行情/规则/公司行为输入内容指纹和读取文件 SHA-256 均写入报告；不读取 Token，不联网补齐缺口。

## 负载记录

固定 20 只沪深股票，2025-01-02 至 2025-12-31，共 243 个交易日、4,860 根原始日线。无下单策略逐 Bar 读取历史尾项并执行日终对账；一次本地测量约 13 秒，`tracemalloc` 记录 Python 分配峰值约 12.2 MiB。

计时包含 `run_backtest` 的清单计算、原生事件构造、运行及对账，数据读取在计时前完成。Python 分配峰值不等同于进程总内存，也不完整覆盖 NT 原生分配。此负载没有大量活动委托；全市场、多年、分钟级与多人并发应按实际工作负载另测。

## 结论边界

本轮验证的是真实供应商数据上的工程路径与账户一致性。转债新增交易语义使用合成测试验证，本地股票湖回放未验证真实转债行情。历史 vintage PIT、券商账单校准、真实排队与开盘容量、策略 alpha、实盘恢复与生产 SLA 保持独立验收。
