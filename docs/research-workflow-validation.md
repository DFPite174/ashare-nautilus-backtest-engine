# P0：代表候选与实际账户反馈验收

2026-11-16，执行核为 **2.6.1**。本批复用现有入口，新增可复跑调用方、独立预期与准入报告，没有改变引擎成交模型或关闭核验。用户授权由本项目选取合理候选；此处验收工作流可用性，未评估策略投资有效性。

## R1：固定用例

| 项目 | 固定约定 |
| --- | --- |
| 候选来源 | 用户授权选定的本地确定性规则，源码 `examples/research_workflow.py`；不冒充 ResearchPod 实际模型生成产物 |
| 股票池 | `000001.SZ`、`002128.SZ`、`600000.SH`、`600519.SH`；为覆盖停牌、实际红利及沪深账户而选，不按本次收益筛选 |
| 区间 | 2025-01-02—2025-06-30；117 个官方交易日，459 根有效日线；停牌日无虚构行情 |
| 策略 | 从样本首日每隔 5 个交易日收盘决策；每股至少 20 根已收盘有效行情，最新收盘严格高于最近 20 根均值者等权；无合格股票则持现金 |
| 可得时点 | 仅当前回调历史和当日收盘已知规则；停牌股历史可能陈旧，估值时间单独输出；不读取明日状态辅助今日规划 |
| 执行 | 次交易日开盘 IOC，一次申报不追单；卖出先于买入；未成交卖款不可用；下次调仓重新读取真实账户 |
| 资金与费用 | 初始 100 万元；默认佣金万三/单笔最低 5 元、卖方印花税万五、过户费十万分之一；实际日程写入 manifest |
| 基准 | 同池、同现金、同日历和费用，每 5 日等权调仓；有手数、资金和停牌约束的账户基准，不是无成本指数 |
| 批量及预算 | 一个候选、一个基准、容量与滑点压力、独立新账户重复，共 5 次；今后本机复跑以 60 秒为排查等待预算。不是行业标准，也不是此前预注册的性能门槛；大池候选吞吐仍属 R7 |

均线直接用原始价格，除息可能改变信号；这是明确的策略定义和局限。历史停牌不补成“每日新观测”。本批不自动搜索均线窗口或按收益调整规则。

## R2：数据与模型准入

| 检查 | 结果与可用范围 |
| --- | --- |
| 来源与快照 | 只读用户本地 `Tushare_DB/lake`；官方日历、原始行情、涨跌停、停牌、证券基础与实施权益；报告保留来源文件哈希、数据快照和代码指纹 |
| 单位与完整性 | 行情不复权，成交量转为股；现有加载器检查日期、单位、缺失开市行情、规则、重复与权益冲突，失败直接中断 |
| 历史股票池 | 显式事件覆盖池；当前基础表上市日期不构成完整历史可投资池或退市生命周期。可用于指定股票账户实验，阻断无偏全市场选股结论 |
| PIT | 供应商当前历史版本；缺少全部原始发布版本及历史修订证据，`historical_vintage_pit=false`，不宣称 strict vintage PIT |
| 权益 | 本区间两项实施现金分红；按登记日实际持仓独立计算应付金额并与实际到账比较；未声称覆盖全部公司行为类别 |
| 成交路径 | 固定 `O-H-L-C` 合成盘口，使用整 Bar 事后成交量；不是观察到的 L2。当前用例仅开盘 IOC，所有零滑点成交独立核对当日真实开盘价；没有盘中限价留单，未声称验证另一条盘中路径 |
| 容量与成本 | 参与率 1% 为基线，百万分之一为容量压力，另加 10 bps 不利滑点；高度敏感的账户结果不得据此推断真实成交或投资优势 |

这些缺口限制研究结论，未通过换股、复权替代记账或默默丢弃失败事件绕开。

```powershell
python examples/research_workflow.py --root "C:\Users\SKT80\Downloads\MyProj\my_upload\Tushare_DB" --output .pytest_tmp_p0_results
```

每次调仓走 `portfolio_signal` → 当时账户快照 → `plan_rebalance` → 原生执行 → 日终核验；下一次决策继续读取实际现金、持仓与可卖量。不是冻结订单带。每组本地 JSON 包含完整订单、成交、拒单、权益、每日账户、计划数量、实际权重、目标偏离及估值时间。偏离是在调仓决策时测量，不能冒充执行完成后的目标达成率。

## R4：独立预期与回归

- `tests/test_research_workflow.py`：部分成交 50 股后，第 2 次调仓读取 **9469.99 元和 50 股实际仓位**（10000 − 50 × 10.50 − 5.01），而非原计划；部分成交在可控小场景验证，本批实际四股回放未观察到部分成交。
- 独立手算：初始 2000 元，10 元买 100 股费用 5.01；次交易日卖出费用 5.51；登记日 100 股、每股 1 元红利到账，最终 **2089.48 元**。同时断言买入日可卖 0、次日实际卖出，清仓后仍收到登记权益。
- 实库股息预期由输入每股红利乘实际登记日股数独立计算；所有组再按逐笔金额和费用独立重算最终现金，并保留原生日终三方核验。
- 原有股票 `T+1`、停牌、共享资金、失败委托、送转上市日测试保留；128 股同刻委托的 full/sparse/orders 回归保留，没有原生默认限流误拒。
- 重复路径一致仅证明可复验，不当作独立市场真值；股息预期与引擎仍共享供应商原始事实，缺少原始事实时不能证明事实正确。

## P0 结论及后续

R1–R4 在上述明确范围内完成：一个用户授权选定的实际数据候选、账户反馈、固定基准、准入限制和独立预期已落地。不是整个平台、全市场策略有效性或实盘验收；ResearchPod 自动联通仍未完成且不属于这次选定用例。

下一步冻结执行核，优先以真实新增候选复用这条流程；只有工作流实际阻塞，再进入 R5/R6 的最小交付调整和 R7 端到端吞吐诊断。原 500 股五年冷启动 20 秒、峰值 1 GiB 目标仍未全部满足，本次小池实验不将它们改写为通过。不自动开始新后端、通用 DSL、券商接入或下一轮热点微优化。
