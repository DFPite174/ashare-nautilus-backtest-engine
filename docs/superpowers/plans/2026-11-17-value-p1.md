# P1 固定实验方案

用户已授权一次完成P1。以下规则在生成目标、运行新策略结果之前固定。

- 区间：2021—2023年36次月度调仓，2020年12月暖启动；不读取2024年后的面板或收益。原V、原始eligibility、Top30等权（不足30只保留现金）、下一交易日开盘、1%参与率、10bps滑点、原费率和现金替代政策不变。
- N：三个已披露完整年度的扣非净利润算术平均值／信号市值，年度窗口沿用原面板`annual_end_year`，三期完整且平均值为正，原TTM盈利收益率也为正。复用上游`normalized_deducted_yield`。
- C：原V排序前要求原三年`cash_quality >= 1`。NC同时使用N排序及C约束；不得先选30只再删不合格者，必须补足至候选不足。
- 覆盖对照：V_COV用原V排序但只保留N有效覆盖；C_COV在同覆盖上叠加现金条件。共V、C、V_COV、C_COV、N、NC六组，未声明的阈值、窗口、权重、缓冲及动量不加入。
- 每组独立账户。共享全部策略选中股票的联合行情快照，复用现有`replay`，保留每日账户与公司行为核查。扩大联合池后先检查V的经济结果与冻结原V一致。
- 主要指标：累计/年化收益、日频最大回撤、年度收益。C对V、N对V_COV、NC对N及C_COV分别比较；收益更高且回撤不差才记为同时改善。覆盖变化单独用V_COV对V、C_COV对C说明。收益/回撤取舍不一致时不强行综合打分。
- 行业：报告平均最大行业权重、单月最大行业权重及医疗保健/地产暴露；候选若单行业单月仍达到30%，安排独立行业上限实验。本轮只评估必要性，不追加限额规则或新回测组。
- 输入：原冻结面板与原财务缓存、本地Tushare湖。缺少三年扣非利润保持缺失；公司行为冲突按原公告裁决或单独核实，禁止静默取最大值、填零或改原库。
- 产物：新调用方样例、针对性测试、私有完整目标/账户与公共聚合摘要；PM报告只使用核心结论、盈亏与行业暴露数据、策略洞察、下一步行动四部分。执行核不改。

步骤：先测试规则，再生成全部冻结目标；读取同源市场并执行六组及候选重复；核对原V、研究结果和行业判据；审查、同步GitHub。研究中的意外数据问题单独记录，不以换参数规避。
