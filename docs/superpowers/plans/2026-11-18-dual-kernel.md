# 双内核最小闭环

目标是让同一份候选从向量化快筛进入事件执行复核，输出可比较的账户结果。复用原 V/R30 的 36 期冻结目标、同一 Tushare 派生行情和既有事件回放入口。

1. 用双边原生日线撮合执行两股、7 日的固定数量样本。逐笔费用按同一口径取分，比较 4 笔成交及 7 日账户。
2. VectorBT 快筛使用次交易日原始开盘价、前一日可知的收盘估值、共享资金、10 bps 滑点和透明的统一费用近似。仅原始行情存在时才尝试下单。记录事件侧完整约束和两侧模型差异。
3. 对比 V/R30 排序、账户指标及执行日目标偏离，保留冻结指纹与本地明细。以既有事件结果校验新运行的经济路径。

验收面向 2021—2023 年的双内核交接。两边的模型差异应体现在报告中，共同规则案例则要求逐笔和逐日一致。
