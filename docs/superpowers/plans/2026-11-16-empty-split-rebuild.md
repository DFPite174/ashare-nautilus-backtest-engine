# 必要优化：空持仓送转的组合重建

2.6.0 交付与本地源文件复核完成后，重新诊断关闭原生最终汇总的版本。128 股/126 日/16000 指令案例中，实时记录约 4.35 秒、日初约 2.06 秒（cProfile，非正常基准）。单独插桩测得 28 次原生组合重建均由当时无原生持仓的证券送转触发，合计约 1.63 秒，账务轨迹与正式基线一致。

最小改动：保存一次 `positions_open` 查询结果，原生桥逐持仓调整后，只有该列表非空才重建原生组合。网关送转、独立参考账本、权益、估值及日终三方对账全部保持，不修改 NT 内部对象或实时统计。

先测试无持仓不重建、有持仓仍桥接并重建，且两者均执行网关和参考权益；再运行完整测试、独立 wheel 和真实本地湖前后三次无 profiler 回放。相同市场摘要、意图和经济配置，逐笔/逐日/订单/权益匹配。另用原五年样本覆盖实际持仓送转。无可重复收益则记录并停止扩展。

该优化不改变输入存储，不能声称解决 1 GiB；公开输入、统计替换和新后端仍暂缓。交付后依据本批结果重新排序下一步。

完成结果：源码与独立安装包各 351 项测试通过；同日同模型三次回放中位数 18.89→17.70 秒，约下降 6.3%。单轮 full/sparse/orders 的 128 股真实行情对照均匹配，原 10 场景及五年轨迹保持，包含实际持仓送转。保留此局部调整，停止扩大权益路径重构；下一步先复核长周期准备峰值而非替换 NT 统计对象。见[验收](../../empty-split-validation.md)。
