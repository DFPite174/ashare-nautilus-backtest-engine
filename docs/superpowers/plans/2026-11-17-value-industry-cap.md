# NC 行业上限固定实验

在生成新目标及运行结果前固定：

- 比较两组：原NC与NC30。沿用2021—2023年36期、原始eligibility、三年正常化扣非盈利排序、三年现金兑现比≥1、Top30等权、次日开盘及全部执行/费用/碎股现金政策；最终留出期封存。
- NC30按原NC分数降序、证券代码升序扫描全部合格候选，每行业最多9只（每只1/30），跳过超限股票后继续补位；不足30只时保留现金，不放松上限。缺失行业归入同一UNKNOWN桶。
- 不改变盈利窗口、现金阈值或调仓频率，不搜索其他行业上限。原NC逐期目标须与P1完全一致，重新回放的经济路径须一致。
- 两组使用同一联合行情。记录被替换股票数、绑定月份、收益/回撤/年度收益/费用，目标行业峰值及实际日末持仓行业峰值；实际行业市值由原始收盘价、逐日真实数量和当时面板标签重建，并核对总持仓市值。
- 目标约束只在月度调仓时应用。实际行业权重按持仓市值/账户权益计算，保留未成交残仓与价格漂移；不增加盘中或额外日度再平衡。
- 首选收益更高且回撤不差的方案；收益与回撤有取舍时分别报告，不追加阈值或事后综合评分。若上限无效或代价高，可保留原NC，并明确下一阶段优先级。
- 复用现有目标/财务函数、账户回放及对账；执行核不改。私有目标和逐股账户保存在本地，GitHub仅同步代码、必要测试及四部分研究报告和聚合结果。

执行顺序：测试排序补位及候选不足处理；验证P1来源并重建NC；冻结两组目标；加载同源行情并回放NC、NC30及NC30重复；重建实际行业权重；审查研究取舍并同步GitHub。
